# 365-Day Thai Communication Curriculum v1

Goal: build practical Thai communication for daily life, travel, relationships, small talk, and natural self-expression.

Learner profile:
- Beginner.
- Uses Traditional Chinese explanations.
- Needs Thai script + romanization + Chinese at the beginning.
- Main goal is speaking and real communication, not grammar knowledge alone.
- Daily lesson length: 30 minutes.

## Core Design

365 days = 52 weeks + 1 final assessment day.

Each week has one main life domain. Each day has one small communication task. The daily PDF generator should create exercises from the weekly theme, while checking history to avoid repeated sentences and repeated task formats.

Daily lesson structure:

```text
1. Today's scene
2. Today's communication task
3. Warm-up review from previous lessons
4. 6-8 core sentences
5. 8-12 useful words
6. Substitution practice
7. Short dialogue
8. Speaking mission
9. Spaced review queue
```

Daily time split:

```text
0-3 min: warm-up review
3-10 min: core sentences
10-18 min: substitution practice
18-25 min: dialogue / role-play
25-30 min: speaking mission
```

Content ratio:

```text
60% review and reuse
30% new material
10% challenge sentence
```

## Romanization Policy

The system should slowly reduce romanization so the learner does not become dependent on it.

```text
Day 1-90: Thai + romanization + Chinese for every sentence.
Day 91-180: Thai first; romanization still shown, but smaller and treated as support.
Day 181-270: romanization only for new sentences, difficult pronunciation, and speaking missions.
Day 271-365: Thai first; romanization only on request or for hard words.
```

## Non-Repetition Rules

Do not make every day completely new. Language needs repetition. Instead:

```text
Exact Thai sentence: never repeat.
Exact dialogue: never repeat.
Main weekly domain: can repeat only in a new phase or a new difficulty level.
Exact daily task: do not repeat within 60 days.
Vocabulary: may repeat, but must appear in a new sentence or new context.
Grammar pattern: should repeat often, but with different vocabulary and situations.
```

Spaced review schedule:

```text
Review yesterday.
Review 3 days ago.
Review 7 days ago.
Review 14 days ago.
Review 30 days ago.
```

The daily generator should include 2-4 review items when those previous lessons exist.

## Weekly Rhythm

Every week follows this rhythm:

```text
Day 1: new scene and survival phrases
Day 2: questions and answers
Day 3: substitution practice
Day 4: short dialogue
Day 5: role-play
Day 6: mixed review with older material
Day 7: speaking test and mini assessment
```

## Four Phases

### Phase 1: Day 1-91, Survival Thai

Main goal: handle basic needs and dare to speak.

By the end of Phase 1, the learner should be able to:
- greet people politely
- introduce self simply
- ask prices
- order drinks and food
- say want / do not want
- use numbers, days, time
- ask for help
- say "I don't understand"
- handle taxi, cafe, restaurant, convenience store basics

### Phase 2: Day 92-182, Everyday Interaction

Main goal: handle back-and-forth daily conversations.

By the end of Phase 2, the learner should be able to:
- talk about routines
- explain reasons
- ask and answer simple personal questions
- discuss preferences
- make appointments
- describe health and feelings
- handle hotel, market, transport, and service situations

### Phase 3: Day 183-273, Small Talk and Storytelling

Main goal: maintain 1-3 minute conversations.

By the end of Phase 3, the learner should be able to:
- talk about today, yesterday, and plans
- ask follow-up questions
- describe experiences
- talk about work, study, hobbies, family, travel
- express opinions simply
- keep a conversation alive with natural reactions

### Phase 4: Day 274-364, Natural Communication

Main goal: express needs, opinions, experiences, and repair communication breakdowns.

By the end of Phase 4, the learner should be able to:
- give longer self-introductions
- describe a problem
- ask for clarification
- correct oneself
- compare choices
- explain why
- handle mixed real-life scenarios
- speak for 3-5 minutes on familiar topics

Day 365 is the final communication assessment.

## Daily PDF Generation Prompt Template

Use this template for an automated Codex job or local generator:

```text
Generate today's 30-minute beginner Thai communication lesson.

Inputs:
- learner language: Traditional Chinese
- current day number: {day_number}
- weekly roadmap item: {week_item}
- history file: generated lessons and used sentence hashes
- review queue: day-1, day-3, day-7, day-14, day-30 items

Output:
- Markdown lesson
- PDF lesson
- history record

Lesson requirements:
- Include Thai script, romanization, and Traditional Chinese.
- Use practical daily-life communication.
- Include 6-8 core sentences.
- Include 8-12 useful words.
- Include substitution practice.
- Include a short dialogue.
- Include one speaking mission.
- Include 2-4 review items when available.
- Do not repeat exact Thai sentences from history.
- Do not repeat exact dialogue from history.
- Reuse old grammar patterns in new contexts.
```
