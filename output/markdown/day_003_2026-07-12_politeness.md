# Day 3: 禮貌語尾和短回應

- 日期：2026-07-12
- 週次：Week 1 / Greetings and politeness
- 今日場景：用簡短回答讓對話聽起來自然有禮貌
- 今日任務：會用ครับ / ค่ะ 做短回答，並用簡單句子回應問候或請求。

## 0-3 分鐘：暖身複習

ได้ครับ
dai khrap
可以、好的。（男生說）

ค่ะ ได้ค่ะ
kha, dai kha
好、可以。（女生說）

## 3-10 分鐘：核心句子

### 1. 好的，可以。（男性短回應）

ครับ ได้ครับ
khrap, dai khrap
好的，可以。（男性短回應）
提示：先用ครับ回應，再補意思，聽起來更自然。

### 2. 好的，可以。（女性短回應）

ค่ะ ได้ค่ะ
kha, dai kha
好的，可以。（女性短回應）

### 3. 好，我等一下就去。

โอเคครับ เดี๋ยวไป
oo-khee khrap, diao bpai
好，我等一下就去。

### 4. 可以，請稍等一下。

ได้ค่ะ รอสักครู่นะคะ
dai kha, raw sak khruu na kha
可以，請稍等一下。

### 5. 謝謝，我等一下回來。

ขอบคุณครับ เดี๋ยวกลับมา
khop khun khrap, diao glap maa
謝謝，我等一下回來。

### 6. 沒關係，請吧。

ไม่เป็นไรค่ะ เชิญเลย
mai bpen rai kha, choen loei
沒關係，請吧。

### 7. 知道了、收到。

รับทราบครับ
rap saap khrap
知道了、收到。

## 10-18 分鐘：替換練習

### 短回答替換
______ ครับ
______ khrap
______。（男生短回應）
可替換：ได้ / โอเค / รับทราบ

### 請對方稍等
รอสักครู่______
raw sak khruu ______
請稍等一下______。
可替換：นะครับ / นะคะ

### 回應後補動作
ได้ค่ะ เดี๋ยว______
dai kha, diao ______
可以，我等一下______。
可替換：ไป / กลับมา

## 18-25 分鐘：小對話

**A**
ช่วยดูอันนี้หน่อยได้ไหมครับ
chuai duu an-nii noi dai mai khrap
可以幫我看一下這個嗎？

**B**
ได้ค่ะ รอสักครู่นะคะ
dai kha, raw sak khruu na kha
可以，請稍等一下。

**A**
ขอบคุณมากครับ
khop khun maak khrap
非常謝謝。

**B**
ไม่เป็นไรค่ะ เชิญเลย
mai bpen rai kha, choen loei
沒關係，請吧。

**A**
รับทราบครับ เดี๋ยวกลับมา
rap saap khrap, diao glap maa
知道了，我等一下回來。

## 25-30 分鐘：口說任務

請用泰語做一段 25 秒短回應練習：先說「好的」，再請對方稍等，最後說你等一下會回來。

ได้ครับ รอสักครู่นะครับ เดี๋ยวกลับมาครับ
dai khrap, raw sak khruu na khrap, diao glap maa khrap
好的，請稍等一下，我等一下回來。

## 挑戰句

โอเคครับ ถ้าเสร็จแล้วบอกผมได้เลย
oo-khee khrap, thaa set laeo bok phom dai loei
好，如果好了就可以直接告訴我。

## 單字

- ได้ / dai / 可以、能夠
- เดี๋ยว / diao / 等一下、稍後
- รอ / raw / 等
- สักครู่ / sak khruu / 一下子、片刻
- กลับมา / glap maa / 回來
- เชิญ / choen / 請
- เลย / loei / 就、吧
- รับทราบ / rap saap / 知道了、收到
- นะ / na / 柔化語氣
- ครับ / ค่ะ / khrap / kha / 禮貌語尾
