# Day 1: 打招呼和禮貌

- 日期：2026-07-11
- 週次：Week 1 / Greetings and politeness
- 今日場景：第一次開口說泰語
- 今日任務：能說你好、謝謝、不好意思、對不起和再見。

## 0-3 分鐘：暖身複習

สวัสดีครับ / สวัสดีค่ะ
sa-wat-dii khrap / sa-wat-dii kha
你好。男生常用 khrap，女生常用 kha。

ขอบคุณครับ / ขอบคุณค่ะ
khop khun khrap / khop khun kha
謝謝。

## 3-10 分鐘：核心句子

### 1. 你好。（男生說）

สวัสดีครับ
sa-wat-dii khrap
你好。（男生說）
提示：khrap 是禮貌語尾。

### 2. 你好。（女生說）

สวัสดีค่ะ
sa-wat-dii kha
你好。（女生說）
提示：kha 是禮貌語尾。

### 3. 謝謝。（男生說）

ขอบคุณครับ
khop khun khrap
謝謝。（男生說）

### 4. 謝謝。（女生說）

ขอบคุณค่ะ
khop khun kha
謝謝。（女生說）

### 5. 對不起 / 不好意思。（男生說）

ขอโทษครับ
kho thot khrap
對不起 / 不好意思。（男生說）

### 6. 對不起 / 不好意思。（女生說）

ขอโทษค่ะ
kho thot kha
對不起 / 不好意思。（女生說）

### 7. 沒關係。（男生說）

ไม่เป็นไรครับ
mai bpen rai khrap
沒關係。（男生說）

### 8. 再見 / 下次見。（男生說）

แล้วเจอกันครับ
laew jer gan khrap
再見 / 下次見。（男生說）

## 25-30 分鐘：口說任務

請用泰語說一段 20 秒：你好，謝謝，不好意思，沒關係，下次見。

สวัสดีครับ ขอบคุณครับ ขอโทษครับ ไม่เป็นไรครับ แล้วเจอกันครับ
sa-wat-dii khrap, khop khun khrap, kho thot khrap, mai bpen rai khrap, laew jer gan khrap
你好，謝謝，不好意思，沒關係，下次見。

## 挑戰句

ขอโทษครับ ผมพูดภาษาไทยได้นิดหน่อย
kho thot khrap, phom phuut phaa-saa thai dai nit noi
不好意思，我會說一點點泰文。

## 單字

- ครับ / khrap / 男生禮貌語尾
- ค่ะ / kha / 女生禮貌語尾
- สวัสดี / sa-wat-dii / 你好
- ขอบคุณ / khop khun / 謝謝
- ขอโทษ / kho thot / 對不起 / 不好意思
- ไม่เป็นไร / mai bpen rai / 沒關係
- แล้วเจอกัน / laew jer gan / 再見 / 下次見
- คุณ / khun / 你 / 您
