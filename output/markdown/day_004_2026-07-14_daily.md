# Day 4: 第一次見面

- 日期：2026-07-14
- 週次：Week 1 / Greetings and politeness
- 今日場景：第一次見面時做迷你自我介紹
- 今日任務：會問名字、說自己的名字，並用禮貌方式說很高興認識你。

## 0-3 分鐘：暖身複習

คุณชื่ออะไรครับ
khun chue a-rai khrap
你叫什麼名字？

ยินดีที่ได้รู้จักค่ะ
yin-dii thii dai ruu-jàk kha
很高興認識你。

## 3-10 分鐘：核心句子

### 1. 你叫什麼名字？

คุณชื่ออะไรครับ
khun chue a-rai khrap
你叫什麼名字？
提示：ชื่อ 是「名字」，ถาม第一次見面的人很常用。

### 2. 我叫 Anson。（男性）

ผมชื่ออันสันครับ
phom chue Anson khrap
我叫 Anson。（男性）

### 3. 我叫 Mee。（女性）

ฉันชื่อมี่ค่ะ
chan chue Mii kha
我叫 Mee。（女性）

### 4. 你也可以叫我 An。

เรียกผมว่าอันก็ได้ครับ
riiak phom waa An gaaw dai khrap
你也可以叫我 An。

### 5. 很高興認識你。（男性）

ยินดีที่ได้รู้จักครับ
yin-dii thii dai ruu-jàk khrap
很高興認識你。（男性）

### 6. 很高興見到你。（女性）

ยินดีที่ได้เจอคุณนะคะ
yin-dii thii dai juu khun na kha
很高興見到你。（女性）

### 7. 這是我們第一次見面。

เจอกันครั้งแรกครับ
juu gan khrang raek khrap
這是我們第一次見面。

## 10-18 分鐘：替換練習

### 問名字替換
คุณชื่อ______ครับ
khun chue ______ khrap
你叫______嗎 / 你叫______？
可替換：อะไร / อะไรนะ

### 介紹自己的名字
ผมชื่อ______ครับ
phom chue ______ khrap
我叫______。
可替換：อันสัน / ต้น / บอย

### 禮貌地說很高興認識你
ยินดีที่ได้______ครับ
yin-dii thii dai ______ khrap
很高興______。
可替換：รู้จัก / เจอคุณ

## 18-25 分鐘：小對話

**A**
สวัสดีครับ คุณชื่ออะไรครับ
sa-wat-dii khrap, khun chue a-rai khrap
你好，你叫什麼名字？

**B**
ฉันชื่อมี่ค่ะ แล้วคุณล่ะคะ
chan chue Mii kha, laeo khun la kha
我叫 Mee，你呢？

**A**
ผมชื่ออันสันครับ เรียกผมว่าอันก็ได้ครับ
phom chue Anson khrap, riiak phom waa An gaaw dai khrap
我叫 Anson，你也可以叫我 An。

**B**
ยินดีที่ได้รู้จักค่ะ
yin-dii thii dai ruu-jàk kha
很高興認識你。

**A**
ยินดีที่ได้เจอคุณครับ
yin-dii thii dai juu khun khrap
很高興見到你。

## 25-30 分鐘：口說任務

請用泰語做一段 25 秒第一次見面自我介紹：先問對方名字，再說自己的名字，最後說很高興認識你。

คุณชื่ออะไรครับ ผมชื่ออันสันครับ ยินดีที่ได้รู้จักครับ
khun chue a-rai khrap, phom chue Anson khrap, yin-dii thii dai ruu-jàk khrap
你叫什麼名字？我叫 Anson，很高興認識你。

## 挑戰句

เราเจอกันครั้งแรก แต่คุยกันสบายมากครับ
rao juu gan khrang raek, dtae khui gan sa-baai maak khrap
我們雖然第一次見面，但聊起來很自在。

## 單字

- ชื่อ / chue / 名字
- อะไร / a-rai / 什麼
- เรียก / riiak / 叫、稱呼
- ว่า / waa / 叫做、說
- ก็ได้ / gaaw dai / 也可以
- ยินดี / yin-dii / 高興、樂意
- รู้จัก / ruu-jàk / 認識
- เจอ / juu / 見到
- ครั้งแรก / khrang raek / 第一次
- นะ / na / 柔化語氣
